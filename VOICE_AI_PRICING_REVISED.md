## Overage Pricing (Critical)

### Original Overage: $0.029/min (60% markup)
```
Cost: $0.018/min
Overage charge: $0.029/min
Markup: 1.61x (61% over cost)
Problem: Too low, encourages overages
```

### Revised Overage: $0.049/min (170% markup)
```
Cost: $0.018/min
Overage charge: $0.049/min
Markup: 2.72x (272% over cost)
Benefit:
  ├─ Discourages overages
  ├─ Encourages upgrading to next tier
  ├─ Generates $0.031/min profit on excess usage
  └─ Much healthier margin
```

### Example: Growth host goes 100 mins over
```
With $0.029 overage:
  100 × $0.029 = $2.90 charge
  "Not worth upgrading to Professional ($50 more/mo)"

With $0.049 overage:
  100 × $0.049 = $4.90 charge
  Month 2 customer thinks: "Wait, this overages will keep
  happening (640 mins/mo > 300 included). I should upgrade
  to Professional ($129/mo includes 750 mins) - same or less cost"

Result: Automatic tier migration ✓
```

## Surge Pricing (For Abuse Prevention)

### Heavy Usage Surcharge
```
If monthly usage exceeds 50% of limit:
  Apply 15% surcharge to per-minute costs

Example: Growth customer uses 450 mins (150 over 300 limit)
  Overage: 150 mins × $0.049 × 1.15 = $8.68
  Encourages: Upgrade to Professional next month
```

### Very Heavy Usage Surcharge
```
If monthly usage exceeds 100% of limit:
  Apply 30% surcharge to per-minute costs

Example: Growth customer uses 600 mins (300 over 300 limit)
  Overage: 300 mins × $0.049 × 1.30 = $19.11
  Message: "You're using 2x your limit. Please upgrade."
```
